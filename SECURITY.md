# Security Policy

## Supported Versions

This is a personal portfolio site, not a distributed package. Only the
latest commit on `main` is maintained.

| Version | Supported |
| --- | --- |
| `main` (latest) | ✅ |
| Older commits | ❌ |

## Reporting a Vulnerability

If you find a security issue, please report it privately rather than
opening a public issue.

- Email: [Jannatunferdos579.ebaub@gmail.com](mailto:Jannatunferdos579.ebaub@gmail.com)
- Or use GitHub's **Report a vulnerability** button under
  **Security** → **Advisories**.

Please include the affected URL, a description of the problem, and steps to
reproduce it. Expect an acknowledgement within a few days.

## Scope

The site is fully static and collects no user data, sets no analytics or
tracking cookies, and has no backend, user accounts, or comment system. The
main realistic risks are a compromised dependency or a supply-chain issue,
which are handled by keeping the dependency set small and auditing
regularly.
